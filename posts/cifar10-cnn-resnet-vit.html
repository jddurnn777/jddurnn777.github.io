CNN vs. ResNet-18 vs. Vision Transformer on CIFAR-10

Or: the project that taught me fine-tuning beats feature-freezing, and a corrupted download taught me to know when to cut losses.
Team project note: this was a four-person final report for EEL4810. Marcus Francois, Yahir Garcia, Ido, and I split the methodology across four notebooks. My pieces were the from-scratch baseline CNN (solo), the evaluation metrics for the frozen ResNet-18 (with Yahir), the fine-tuning and evaluation of the ResNet-18 (with Ido and Marcus), and the Vision Transformer built from scratch (with Marcus). I'm writing up the whole comparison for context, but the parts below are the ones I actually built.

The question

Image classification on CIFAR-10 is a classic way to ask a very practical question: is it better to train a small model from scratch, or to borrow features that a much bigger model already learned on ImageNet? We tested four points along that spectrum — a CNN with zero pretraining, a frozen pretrained backbone, a fine-tuned pretrained backbone, and a Vision Transformer built entirely from scratch.

Baseline: a CNN from nothing

My starting point was a plain CNN in PyTorch — three conv blocks (32 → 64 → 128 channels, 3×3 kernels, ReLU, max pooling after each), flattened into a small classifier head (Linear → 256 → ReLU → Dropout(0.3) → Linear → 10). Adam optimizer, cross-entropy loss, 15 epochs, an 80/20 train/validation split, fixed seed throughout for reproducibility.

The first run overfit — training accuracy kept climbing while validation accuracy plateaued, a pretty textbook sign the model was memorizing rather than generalizing. Adding random horizontal flips and random cropping (with padding) closed that gap noticeably.

Transfer learning, two ways

Yahir and I then tried freezing a pretrained ResNet-18's convolutional backbone entirely and training only a new final classification layer. The idea: reuse ImageNet's learned visual features, and only teach the model how to map those features to CIFAR-10's 10 classes.

Ido, Marcus, and I then unfroze the last residual block (layer4) and the classifier head, and fine-tuned with a much lower learning rate (pretrained weights need gentler updates than randomly initialized ones) plus a fuller augmentation pipeline — flips, crop-with-padding, color jitter, small rotations, and label smoothing to reduce overconfidence.

Vision Transformer, from scratch — and a dead end that became MNIST

Marcus and I built a ViT-Tiny-style Vision Transformer completely from scratch, following Akshay Gokhale's guide on training a ViT on CIFAR-10: patch embedding via a strided convolution, a learnable CLS token, learnable positional embeddings, multi-head self-attention, and pre-norm transformer encoder blocks — twelve of them, about 5 million parameters total, trained with AdamW, OneCycleLR, and MixUp/CutMix augmentation.

The plan was to run this on CIFAR-10 too. It didn't cooperate — the dataset download failed with a 503, and the fallback manual extraction turned up a corrupted archive. Under a real deadline, we made the call to swap in MNIST instead, purely so we could still fully build, train, and validate the transformer architecture rather than burn the rest of the project debugging a dataset download. It's a smaller, easier dataset, and the results below aren't an apples-to-apples comparison because of it — which is exactly the caveat I'd want if I were reading someone else's report.

Finding: the frozen ResNet-18 landed at almost exactly the same accuracy as the un-augmented CNN baseline (77.45% both). That's not a coincidence worth glossing over — it means simply having access to ImageNet's pretrained features bought us nothing by itself. The backbone's representations were frozen and couldn't adapt to CIFAR-10's specific visual patterns, so the model was limited to whatever a single trainable layer could squeeze out of features tuned for a different dataset.
Finding: unfreezing just the last residual block and fine-tuning with a low learning rate jumped accuracy to 94.47% — a 15–17 point improvement over both the frozen model and the from-scratch CNN. Letting even a small part of the pretrained network adapt to the target dataset mattered far more than which model we started from.

The most common confusions in the fine-tuned model's classification report were the ones you'd expect from a human squinting at small images too — cat mistaken for dog and vice versa, truck for automobile, ship for airplane. Visually similar classes stay hard even for a 94%-accurate model.

What I'd take into the next project

  • Confirm a dataset downloads and extracts cleanly before building the model that depends on it — the CIFAR-10 → MNIST swap cost us a clean comparison.
  • Re-initialize a model from pretrained weights before any additional retraining run, to keep runs independent rather than accidentally continuing from a previous run's state.
  • Actually run the Vision Transformer on CIFAR-10 once time allows — I'd like to know whether it would outperform the fine-tuned ResNet-18 on the harder dataset, or whether a smaller transformer just memorizes a smaller dataset instead.
